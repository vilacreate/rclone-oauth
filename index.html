rclone Drive Integration

This is a private, personal-use integration used to connect rclone to the owner's Google Drive account.

Purpose

The integration is used to securely synchronize encrypted files between a personal computer and Google Drive.

Files are encrypted locally using Cryptomator before being uploaded to Google Drive. Google Drive therefore stores the encrypted vault files rather than the original photos, videos, or other private files.

Google Drive access

Google Drive permissions are used only so that rclone can read, upload, update, and synchronize files in the owner's Google Drive.

This application is intended solely for personal use and is not offered as a public service.
