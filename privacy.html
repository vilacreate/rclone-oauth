Privacy Policy

Last updated: November 8, 2026

This rclone Drive integration is a private application intended exclusively for the personal use of its owner.

Google user data

The application accesses Google Drive data only for the purpose of reading, uploading, updating, and synchronizing files using rclone.

Google user data is not sold, rented, shared with advertisers, or provided to unrelated third parties.

Data storage

The website does not operate a server-side database and does not collect Google Drive files.

OAuth authorization information used by rclone is stored locally on the owner's device in the rclone configuration.

Encrypted files

Private files are encrypted locally with Cryptomator before being synchronized to Google Drive. The Google Drive storage therefore contains the encrypted Cryptomator vault data.

Use of Google API data

Access to Google user data is limited to the functionality required for personal file synchronization. The data is not used for advertising, profiling, analytics, or artificial intelligence training.

Revoking access

Access can be revoked at any time through the security settings of the owner's Google Account.
